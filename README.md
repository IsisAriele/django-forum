# django-forum

## Primeiros passos

Criando ambiente virtual:

```bash
python -m venv env
```

Ativando ambiente virtual:

```bash
source env/bin/activate
```

Instalando as dependências:

```bash
make dependencies
```

Rodando as migrações:

```bash
make migrate
```

Criando super-usuário

```bash
make create-user
```

Rodando servidor:

```bash
make runserver
```
